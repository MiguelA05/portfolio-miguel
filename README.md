# Miguel Angel Mira Ortega · Portafolio

Sitio personal bilingüe orientado a oportunidades junior de backend con Java y Spring Boot. Presenta tres casos técnicos, un archivo de proyectos y enlaces de contacto.

## Abrir el sitio

Abre [index.html](index.html) en un navegador para la versión inglesa o [es.html](es.html) para la española. El selector de la esquina superior izquierda cambia entre ambas. Las páginas usan [CSS local](css/app.css) y la fotografía de [assets](assets).

## Actualizar un proyecto

Edita la sección `#works` en ambos archivos HTML. Conserva el mismo enlace de repositorio en las dos versiones y traduce la descripción y el texto del enlace. Si añades un proyecto al archivo desplegable, actualiza su contador.

Para comprobar el cambio, abre los dos idiomas en escritorio y móvil, navega hasta los proyectos, despliega el archivo y verifica el destino del enlace.
